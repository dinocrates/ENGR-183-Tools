Unit 8 · Midterm Project

Solar-Panel Analysis and Technical Report

Use MATLAB to recommend a solar-panel system for a campus charging station. Compare performance, reliability over the supplied observations, and calculated component costs. The assignment supplies every equation, constant and decision rule.

Your workflow

  1. Read the assignment guide and open the preloaded MATLAB files.
  2. Import and clean the data using one shared row mask.
  3. Calculate power and performance summaries from the supplied equations.
  4. Calculate quantity × unit price and sum component costs in your helper. Use if/elseif/else to classify all four outcomes.
  5. Recommend the least expensive qualifying system and create two labeled figures.
  6. Write a 3–4 page report supporting the recommendation with numerical evidence.

What to submit

LastName_SolarStation_Report.pdf, SolarStation_Analysis.m, evaluate_system.m and any extra helpers. The report includes purpose, data and methods, results, discussion and recommendation. Run Tests provides programming feedback; you submit the finished work in Canvas.
