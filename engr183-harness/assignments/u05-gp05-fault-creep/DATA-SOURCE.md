# Data source — Parkfield XPK2 creepmeter

`parkfield_xpk2_daily_excerpt.txt` contains the final 40 records from the USGS daily archive file for Parkfield creepmeter station XPK2 as downloaded for this course package on September 1, 2026.

- Agency: U.S. Geological Survey, Earthquake Hazards Program
- Station: Parkfield #2 (`XPK2`)
- Product: daily creepmeter values
- Original archive: `https://escweb.wr.usgs.gov/share/langbein/Archive/CREEP/DAY/xpk2.day.gz`
- Documentation and station table: `https://earthquake.usgs.gov/monitoring/deformation/data/download.php`
- Columns: year, day of year, scaled surface-fault slip in millimeters

The USGS documentation notes that creepmeter data measure surface fault slip, many instruments sample every 10 minutes, and recent values may be unreviewed. This frozen excerpt is used so every student receives identical input. It must not be presented as a hazard forecast.
