# Data source — Lake Perris daily storage

`lake_perris_storage_2025Q1.csv` is an unmodified CSV response downloaded from the California Data Exchange Center (CDEC) on September 1, 2026.

- Agency: California Department of Water Resources
- Station: Lake Perris (`PRR`)
- Sensor: 15, `STORAGE`
- Duration: daily (`D`)
- Period: January 1 through March 31, 2025
- Units: acre-feet (`AF`)
- API request: `https://cdec.water.ca.gov/dynamicapp/req/CSVDataServlet?Stations=PRR&SensorNums=15&dur_code=D&Start=2025-01-01&End=2025-03-31`
- Capacity reference used by the assignment: 131,452 acre-feet, as listed for Lake Perris in CDEC reservoir reporting.

The file is frozen so student results and automated tests remain reproducible. Students are auditing and summarizing published observations; they are not making reservoir operating decisions.
