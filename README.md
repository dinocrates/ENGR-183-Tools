# ENGR-183 Tools

Browser-based tools for ENGR-183 (Programming with MATLAB for Engineers and Scientists) at MSJC. Each tool lives in its own top-level folder and can be built/deployed independently.

## Tools

- [`octave-playground/`](octave-playground/DESIGN.md) — in-browser Octave playground (JupyterLite + xeus-octave), fallback and consistency layer for students who can't run a local Octave install. See its `DESIGN.md` for the full design and milestone tickets.

More tools (visualizers, calculators, graphing tools) will be added here as their own folders.
